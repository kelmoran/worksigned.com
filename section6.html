The tools built into WorkSigned

Our platform contains a wide array of productivity tools to aid the research and publication process.

Overview

WorkSigned has a rich tool ecosystem that is self contained within the client. When a user wishes to view, access, or edit their files or databases, they may choose to do so within WorkSigned without ever leaving the client. However, this is completely optional. WorkSigned's primary mission is to provide frictionless signing of project documents and data.

How the built in tools work

When the user selects any supported file or database from their explorer panel (found on the left hand side of the interface, which shows the researcher's data sources and the files within), the client's main window automatically opens the file with the appropriate program. Nearly all of the built in programs can create, read, and edit the file formats they support. This provides the necessary convenience to do routine tasks that would otherwise require frequent switching out of the client.

Do I have to use AI tools, web search, and email within the client?

It is highly recommended - as this is the only feasible method that these activities can be attested to. One cannot attest to third party traffic that does not pass through the WorkSigned platform. Such verbal attestations without signed records would be weak, and it would be difficult to acquire such evidence from AI/search/email providers themselves. By using an institution-controlled relay that the user cannot access, we can provide some assurances that the contents of the record were not tampered with, and thus provide a stronger legal standing to the attestations.

Do I have to use the other viewer and editing tools?

They are optional. Data generated on the user's own machine and on their own terms does not face the same scrutiny from a record signing standpoint.
