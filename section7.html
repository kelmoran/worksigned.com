What can be customized

Virtually all components of WorkSigned's workflow and features are easily customizable.

Overview

Customization and extensibility is a core philosophy of WorkSigned software. Data access methods are constantly evolving, and as such we have made the client adaptable to the researcher's technical needs. WorkSigned updates its software with new adapters (eg to new data sources) to meet customer needs at no additional cost. Furthermore, each research project is different. The research record assembly pipeline, which is AI powered, is highly customizable to the researcher's need.

What components of WorkSigned are customizable?

1. The data source adapters. Connection and integration to new cloud storage providers and new data storage/transfer protocols, for example.

2. The built-in tools. WorkSigned accommodates almost any type of additional tool. Adding a new tool is part of the client design and does not conflict with other tools.

3. Research record generation pipeline. An AI pipeline helps categorize files/data, generate metadata, and create additional insights into the record. WorkSigned includes a pipeline editor to customize, replace, or create new pipelines that are more suited towards specific types of research.

4. AI/email/web search tooling. AI tools are originally highly customizable. Researchers will eventually need to adapt AI tools to specific needs. WorkSigned anticipates this and provides a modular and flexible AI agent stack. Email provider integrations can be added on demand free of charge. Web search providers can be added on demand free of charge.

I would like to customize something special, is it possible?

Please contact us for special requests for customization. There is a high chance that it is and we would be happy to walk you through it. WorkSigned's design philosophy favors customization heavily and in the event that something isn't already customizable, we would be happy to make it so provided it does not disrupt the program's core functionality.
