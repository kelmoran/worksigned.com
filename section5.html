Data Integration

How research data integration works

WorkSigned supports integration of local and cloud infrastructure into the research record.

Overview

The primary problem for generating a complete research record is that project data can be scattered in many locations. WorkSigned solves this problem by interacting with all of them and acting as a central hub for project data. So long as the data is accessible via a public facing interface (most are), the user need not do additional work beyond the initial setup - WorkSigned takes care of the rest.

How WorkSigned acts as a data hub

For every data source that the researcher has, starting with their laptop or workstation, WorkSigned connects to and integrates with that source. The architecture is extensible and additional sources can be added on demand.

What a central hub for project data means

The researcher not only keeps their workflows the same, but can more easily track, inspect, and work on their research. WorkSigned has built in tools for the researcher to view and edit all of the data within the hub. This provides for an enhanced user experience and avoids costly and unwanted data migrations.
